Início rápido da API

1. Crie uma conta

Se você ainda não tem conta no GluView, crie uma — a API pública sempre opera em nome de uma conta existente, nunca de forma anônima.

2. Gere uma API Key

No portal web, autenticado, chame:

A resposta traz a chave completa uma única vez (glsk_...) — guarde agora, ela não pode ser recuperada depois (só um prefixo não secreto fica visível para auditoria). Criar, rotacionar ou revogar uma chave exige reautenticação recente (login há menos de 15 minutos) — veja autenticação.

4. Trate erros e limites

Toda resposta de erro da API pública vem em Problem Details com um código estável (code) — nunca só um status HTTP solto. Respeite o cabeçalho Retry-After em respostas 429.
